# 初筛报告文风指南

项目概况以事实性介绍为主；多维评价给明确方向和简明理由；下一步建议只写会影响判断的关键工作。以下要求适用于正式撰写和合稿润色。

## 基本写法

1. 事实写具体对象、动作、阶段、数字与口径；评价先给判断，再给支撑理由。没有数字时用已有具体事实，不为消除空泛而补造数据。
2. 一个段落讲清一个话题，重点适当展开，次要信息一句带过。允许长短句变化，避免一句一段或通篇均匀罗列。
3. 有依据就明确表达；真的缺信息就写“无法判断”。同一处不确定性说明一次，避免在每项判断后重复追加否定式限定。
4. 事实部分不加入公司的宣传性自夸；投资判断与公司披露、管理层陈述分别表达。预测和计划保留未来语态。
5. 数字保留期间、币种、单位和必要分母，正文关键数字及事实使用脚注。来源定位放在附注，不以反复堆来源字样打断正文。
6. 风险写会如何影响本金、增长或退出；保留真正必要的条件和不确定性，删除没有项目针对性的套话。

## 章节层级与段落组织

固定报告框架规定内容覆盖和顺序，框架内的小节按本次材料自动组织。写作前先判断每节有多少独立子话题，合稿后再检查读者能否通过标题定位所需内容。

- **何时分节**：一节涉及多个业务领域、多个需要分别展开的分析对象，或较长内容中存在明显主题转换时，应增加下一级标题。只有单一主题时，优先通过自然分段改善阅读；一个短段或一张表已讲清的内容，保留简洁结构。
- **如何分组**：多业务项目优先按业务领域设小节，同一领域的需求、市场阶段、对手、壁垒和终局集中呈现。确有实质差异的地区、产品或客户群可以作为分组依据；同层标题采用一致的分类方式，避免交叉重复。
- **如何命名和控制深度**：标题简短具体，说明该节讨论的对象或问题。保持既有主框架，通常只在主题下再细分一层；例如模板中的“行业与竞争”为三级标题，其业务小节使用四级标题。层级不得跳跃，不用加粗标签代替真实标题。不按固定字数切割，不强制各节具有相同数量的小节。
- **如何安排段落与表格**：每个段落围绕一个话题；将过长段落按“市场机会、竞争事实、投资判断”等自然转折拆开，避免一句一段。表格放在对应小节内，口径说明及解读与表格相邻，来源脚注随所支撑的事实移动。
- **简短内容**：“一段话总结”保持一段，七项评价仍采用一句话理由与星级，风险评价保持简短段落；项目归类及后续工作保留模板表格，不为形式对称增加标题。

例如，长篇、多产品线的行业章节可用“市场边界与规模”作总览，再按各业务领域分别展开；只有单一产品、两段行业说明的项目可直接保留连贯段落。示例用于说明组织方式，不是各项目必须复制的标题清单。

仅优化层级与表达时，保留原事实、数值、表格数据、来源关系、评价和建议。检查拆分后是否出现孤立标题、信息重复或脚注脱离事实；发现实质问题另行按证据规则处理。

## 核验过程与正文

除非存在影响判断的重大冲突，正文不叙述常规核验、印证、检索及来源比对工作，例如“公告可核验”“获某网站补充印证”“工商页面可识别”“本次已检索”。直接写事实或判断，来源、核验路径及非重大差异放入数字脚注、来源附注或底稿。

重大冲突应简洁说明不同口径及对判断的影响；影响估值、风险或项目归类的关键未知项仍应保留。“公司披露”“FA称”等必要的证据身份，以及预测、含税／不含税、出货／收入等业务口径照常表达，不因删去过程叙述而改变事实的确定程度。

例如，“创始人为计算机专业硕士，获校友网补充印证”改为“创始人为计算机专业硕士”，保留原脚注；含税出库金额与财务收入存在较大差额时，正文保留差异及其对估值分母的影响。

## 常见问题与修法

| 问题 | 修法 |
|---|---|
| “值得注意的是”“综上所述”等填充过渡 | 能删则删；需要连接时明确因果、对比或递进 |
| “在当今……背景下”等铺垫 | 从公司正在做的事或关键事实开始 |
| 为完整感硬凑三点、三维度 | 按信息重要性和真实关系组织 |
| “里程碑”“注入新动能”等意义拔高 | 写具体机制、影响对象和幅度 |
| “积极向好”“韧性强”“空间广阔”等空泛定性 | 改为现有数字或可识别事实；没有依据则删 |
| “不仅……更……”“并非……而是……”等贬褒对冲 | 直接陈述主要结论 |
| “或有望在一定程度上”等多重限定 | 留必要的一个限定；信息不足则明确缺口 |
| “赋能”“闭环”“生态”等黑话装饰 | 改为谁向谁提供什么、如何收费或创造价值 |
| 四字词连续铺陈 | 改为自然中文和具体动作 |
| 每段加粗标签、装饰符号和标题党 | 保留有用的层级，去掉装饰；评分星级及既定表格保留 |
| 一句话一段、把平行短句拆得零碎 | 合并为完整话题段；必要的比较保留表格 |
| “未来可期”“持续关注”等空洞结尾 | 写具体下一动作及完成标准 |
| 罗列数据后只说“表现亮眼” | 在有依据时解释数据对判断的意义 |
| 把相关性写成确定因果 | 补充机制证据或按实际把握调整表述 |
| 英文直译语序与重复“我们认为” | 改为自然中文，直接表达结论 |

## 适合初筛的段落

- **总结**：公司做什么、进展怎样、融资要点是什么、初步归类及主要理由是什么，串成一段话，不铺宏大背景。
- **行业**：围绕产品线明确细分市场，讲清机会、阶段、需求与竞争，数字的行业口径一致。不要把大行业规模直接当作公司机会。
- **公司与商业化**：产品、客户验证、正式订单、交付与收入分清阶段。按产品线写真实进展，不强制用同一组指标覆盖所有业务。
- **评价**：一句话理由加星级。理由指出决定判断的事实，避免只把“较好”“较差”换种说法。
- **风险**：首句点明风险高低，随后说明主要损失机制。分析的是七年基金存续期内本金永久损失的可能性。

以下例子只演示表达，数字为虚拟，不作为真实项目材料：

| 原表达 | 改写 |
|---|---|
| 公司积极赋能客户，产品商业化进程取得显著突破。 | 公司产品已通过两家客户的技术验证，其中一家进入采购准入，尚未取得正式订单。 |
| 公司不仅拥有雄厚技术实力，更具有广阔市场空间。 | 创始人曾负责同类设备研发；产品当前处于客户测试阶段，量产交付能力仍待验证。 |
| 风险包括宏观波动、行业竞争、政策变化等。 | 项目风险较高。当前收入尚未成规模，后续研发依赖新增融资；若融资延迟，产品上市和退出时间都会后移。 |
| 建议加强尽调、持续跟踪。 | 取得前两大客户的验证节点及采购计划，确认是否存在未来一年内可兑现的正式订单。 |

## 润色与自检

默认采用中度表达整理：删填充、调整句序、合并碎段、把空泛表述落到已有事实。保留作者观点、数字、评级及报告固定框架；发现事实或逻辑问题先回到分析和来源，不能通过润色悄悄改结论。

检查是否存在无依据形容词、硬凑并列、重复限定、碎段、无意义加粗、弱因果和空洞结尾。正文无需附“去 AI 化”说明或编辑过程。缺失财务数据按报告指南留空，缺口进入分析记录和必要的后续工作，不在报告反复插占位符。

方法归属：内化用户选定的中文金融研报去 AI 化写作规则及摘要、行业、公司分析、风险段落方法，并结合初筛报告要求整理。千字周报的段落数量、情绪化标题及其他文类的输出格式不适用于本报告。
