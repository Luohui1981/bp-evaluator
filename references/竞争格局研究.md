# 竞争格局研究

生成或修订「行业与竞争」时使用。本方法负责找全主要参与者、判断竞争格局，并为产品差异化和市场机会评价提供依据。

## 1. 界定细分市场和地域

- 按项目产品线界定产品用途、目标客户、购买场景和替代关系，覆盖在研产品线。区分直接对手、替代方案（含客户自研）和潜在进入者。每个主体映射到具体产品线，避免把相邻市场厂商混进份额排名。
- 对中国和美国分别判断发展阶段、参与者、份额口径及格局是否趋稳。按实际销售、部署或服务区域判断市场归属，同时记录企业所在地；跨市场企业按当地业务分别记录。全球、地区、渠道样本各用各自口径。阶段处于过渡期或证据不足时，先查两类来源，再据实际竞争格局选择分析口径。若政策、准入、数据、渠道或客户采购形成实质隔阂，在正文分开介绍两地主要企业和竞争格局，并简述隔阂的依据。

## 2. 成长后期至成熟期

1. 优先查买方或卖方行业研报、已识别同行上市公司的深度研报、近三年内上市同行的招股书，以及行业协会和调研机构的新闻与报告。三年从证据截止日往前算，以实际上市日为准。沿榜单、同业对标和引用找到原始统计，再查上市公司披露、一级市场融资新闻、产品推广及企业 PR，补充榜单之外的候选。
2. 找出主要领先者并核对份额。注明产品定义、地域、统计期、渠道覆盖和份额指标（如销量、出货量或收入）。优先使用同口径的完整头部排名或已发布集中度。同口径的前 N 名及其份额齐全时，CRN 为这 N 家份额之和，按证据给出 CR3、CR5 或 CR10 中适用的指标。以公司或集团为统计主体时核对品牌归属及统计期间内的并表口径。不同分母、时期或地区的份额分别保留，冲突写明差异及暂用口径。
3. 主要企业和大致份额得到支持时，交代头部格局。市场分散时，仍列代表性知名企业，并用参与者数量、区域分布或头部份额等证据说明分散判断。集中度、产品差异化与进入壁垒分别判断。份额或分母缺失时，写清已掌握的主要企业及覆盖范围，把份额或格局留待核实。

## 3. 导入期至成长早期

- **创业公司。** 优先查中美创业媒体、科技媒体、公开融资公告和投资方披露。消费产品补查产品推广和渠道上架，高科技补查技术论文和行业报告。公开融资从细分市场最早可追溯的报道查至证据截止日，沿中英文名称、曾用名、品牌名和投资方反查。按主体和轮次去重，区分转载、同轮分批披露和独立轮次，日期、金额、估值或轮次无法确定时据实留空。已退出、并购或转型的案例保留历史状态。
- **上市公司及产业巨头。** 并行查年报、公告、财报电话会和产品发布，用细分品类、潜在切入者名称及新业务关键词检索。上市身份是领先性的正向信号，结合该业务的产品、资源投入、渠道、客户和交付进展判断竞争地位。未披露专项融资但已有产品、渠道或商业化证据的企业可入选。合作、产品预告、概念展示、研发或验证、预售待交付、正式商用分别记录；有直接竞争的已商用产品纳入主要对手，有相关布局的研发或概念项目列为潜在进入者。
- 逐家说明领先的维度及证据，如融资或估值、品牌或产品知名度、可比份额、实际商业化进展。不同维度可指向不同企业，排序和相对位置按证据表达。按证据截止日判断当前竞争，历史融资和战略预告保留其时点与状态。

## 4. 多渠道查漏和核验

1. 中文查普通网页和微信公众号。微信使用 `wechat-article-downloader`，优先查已确认的官方账号，按该 Skill 处理全域候选和同名账号。候选待确认期间继续其他渠道。使用文章时定位原文、公众号、日期和段落，标明公司披露、独立报道或转述。入口及工具选择见 [Skill 主流程](../SKILL.md#1-确定资料与口径)。
2. 英文查普通网页，并分别定向搜索播客和 YouTube。播客可用节目目录、BidClub 或节目官网发现，YouTube 可用站内搜索或限定 YouTube 域名的公开索引。找到相关节目后核对原始发布者、嘉宾或说话人、日期和对应时间戳，使用原始节目链接。搜索摘要、转述和未经核对的字幕先作线索。以节目发现的融资、份额和产品进展，优先回溯公告、原始统计或正式产品披露。
3. 用中英文行业异名、技术路线和应用场景拓宽候选。沿入选企业、投资方组合、研报同业表和文献引用反查两地名单，并定向核对主要候选、别名、融资及产品状态。完成各渠道及两条早期线索的首轮搜索后，按本轮新增线索做一轮补查；有新增合格企业或融资案例则继续，直到一轮没有新增。若渠道受限、关键候选待确认或证据无法取得，在覆盖记录中说明并保留待核项。AlphaClaw 同步使用 AlphaEngine CLI 补查。

## 5. 底稿与正文

- 在 [工作区适配](工作区适配.md) 指定的行业底稿或分析记录内，保留市场定义、阶段依据和检索覆盖（市场、关键词、渠道、时间范围、补查结果及缺口）。企业记录至少有主体及别名、上市状态、市场与产品线、竞争关系、业务状态和日期、领先证据、纳入或排除理由及来源定位。早期融资按事件保留轮次、日期、披露金额与估值口径、投资方和来源。
- 正文按产品线写主要企业及其业务、集中度或领先依据、当前格局及对项目的影响。关键事实用数字脚注，过程和完整名单留在底稿。区分当前格局与未来终局，终局判断沿用 [竞争壁垒分析](竞争壁垒分析.md)。交付复核是否跑完约定渠道及查漏，未覆盖的范围和影响判断的证据缺口写入待核事项。
