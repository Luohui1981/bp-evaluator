# 多维评价与下一步建议

依据用户手写评价标准及其确认的估值边界整理。七项评价均采用“一句话理由｜初步判断”表，每项一至三颗星；证据不足以判断时明确写“无法判断”并说明关键缺口，不以缺数据代替负面评价。科创板计划和产业协同的加星分别只作用于公司成熟度和投资策略契合度，每项加星后最高仍为三星。

保持用户的定性投资偏好，不额外建立量化权重模型、总分、平均分或按总分归类。创始人至少一半权重属于团队评价的判断侧重。金融指标使用已明确的会计期间及口径，预测与历史实际分开。

## 团队评估
- 内容：

| 评估理由  | 初步判断 |
| ----- | ---- |
| 一句话理由 | ⭐⭐⭐  |

- 分析指南：
  - 从创始人背景、团队完整性、股权结构三个维度来判断，最高三颗⭐，最低一颗⭐
  - 判断时，对创始人应给与至少一半的权重。最佳的创始人应该有与当前公司相关的成功创业经历；对to B类业务和先进制造业，行业大厂高管或具备资深专业经验是必要条件；无实业界经验的科学家创业不应给与高分，除非其掌握独家核心技术；对to C类业务和AI等前沿科技，年轻科学家和优秀的年轻人可给与比较高的评价。
  - 团队完整性方面，关键看是否有核心高管能补足创始人的短板。研发产品型创始人需要有商务销售类助手，市场销售类创始人需要好的CTO，硬件类公司一般不能缺生产供应链的行家。
  - 核心团队的股权份额不宜太低，早中期不应低于50%，后期不应低于30%。控制权必须集于一人，绝对不能两三个联合创始人股权平均分配。
  - 如果该公司是某成熟的行业龙头公司分拆出来的子公司，则对团队股权比例的要求可降低。
## 商业模式
- 内容：

| 评估理由  | 初步判断 |
| ----- | ---- |
| 一句话理由 | ⭐⭐⭐  |

- 分析指南：
  - 判断这是不是一个好生意，最高三颗⭐，最低一颗⭐
  - 好生意是有竞争壁垒的，能形成很强的竞争优势的，所以五大商业模式中，平台型>产品型>订单型=连锁型>项目型。
  - 好生意一般会有稳定且较高的ROE和净利率，且行业集中度较高。所以，对比较成熟的产业，可以看公司所在细分行业内的上市公司是否具备稳定的的15%以上的ROE和净利率，可以看细分行业的前几大厂商是否长青。

## 市场机会
- 内容：

| 评估理由  | 初步判断 |
| ----- | ---- |
| 一句话理由 | ⭐⭐⭐  |

- 分析指南：
  - 根据公司产品线面对的市场机会的大小给出评估，最高三颗⭐，最低一颗⭐
  - 最大的市场机会：颠覆性技术变革带来全新的市场需求，会形成全新的行业或重塑行业格局。比如互联网、能源革命和现在的AI大模型。
  - 次一级的市场机会包括：人口代际、消费趋势、新的市场，如 一人经济、银发、出海、情绪消费等等；技术进步撼动旧的产业格局，给新玩家带来机会，如电动化给整车和关键零部件带来机会；地缘政治竞争带来的新机会，比如中国在高科技硬科技领域的国产替代。
  - 在次一级的市场机会中，如原行业竞争壁垒本身很高，给新玩家的机会窗口会比较窄；地缘竞争带来的机会也同时是风险，在中国市场获得的机会可能被全球市场丧失的机会所抵消。

## 公司成熟度
- 内容：

| 评估理由  | 初步判断 |
| ----- | ---- |
| 一句话理由 | ⭐⭐⭐  |
注：不是仅评估公司成熟度，而是评估公司的成长确定性。

- 分析指南：
  - 不是越成熟越好，也不是越早期越好，而是越具备确定的成长性越好，最高三颗⭐，最低一颗⭐
  - 分数最高的应为“导入期-成长期-成熟期-衰退期”中成长期中后段。这个时期应具备如下特点：已实现规模化的收入和规模化的净利润，但未来几年内市场需求和公司收入的预期增长率仍达到20%左右或更高。
  - 其次，应为成长早期和成熟期早期。成长早期的特点是：产品已进入“早期大众”，收入成规模且高增速，但净利润可能不高。成熟早期的特点是：利润高，新增投入降低，所以现金流好，但收入增速一般已降至15%以下。
  - 导入期的成长潜力大，但确定性低，此时往往收入规模小甚至无收入，产品还在验证，行业技术路线也未定型，主流客户还在观望。
  - 考虑到资本市场对未盈利科技企业的支持，如果是符合中国政策的硬科技企业（如半导体、量子、航天、脑机、大模型、创新药、核聚变等），即使处于导入期或成长早期，只要已有未来一年内明确申报科创板的计划，可增加一颗⭐。明确计划最低标准：已完成股改并进入辅导阶段。

## 盈利能力
- 内容：

| 评估理由  | 初步判断 |
| ----- | ---- |
| 一句话理由 | ⭐⭐⭐  |

- 分析指南：
  - 盈利能力越强则评分越高，最高三颗⭐，最低一颗⭐
  - 财务质量主要看如下指标：净利润、净利率、ROE、经营现金流，如果净利润和经营现金流都是负数，最多一颗⭐
  - 最近一年净利润达到亿元人民币，净利率和ROE都达到10%，且经营现金流为正，才能评三颗星。
  - 如凭借可得信息无法判断，则写“无法判断”

## 估值合理性

每项输出“一句话评估理由｜初步判断”，一至三颗星；信息不足写“无法判断”。当年指报告证据截止日所在年度；区分公司预测、已实现数据与本次计算，不凭年内累计数据自行年化填补全年预测。

规模性盈利定义为当年净利润严格大于 5,000 万元人民币；规模收入定义为当年收入严格大于 1 亿元人民币。先判断是否规模盈利，若是使用 PE；否则有规模收入使用 PS；当年预期尚无规模收入时，按硬科技／非硬科技使用绝对估值。无法确定所属档位时写“无法判断”，不猜测收入或利润。

| 适用情况 | 指标 | ⭐⭐⭐ | ⭐⭐ | ⭐ |
|---|---|---|---|---|
| 当年规模性盈利 | 当年动态 PE | 小于 30 倍 | 30—100 倍，含两端 | 大于 100 倍 |
| 当年利润不高或亏损，但收入已成规模 | 当年动态 PS | 小于 3 倍 | 3—10 倍，含两端 | 大于 10 倍 |
| 当年预期尚无规模收入，硬科技 | 股权估值，人民币 | 小于 10 亿元 | 10—50 亿元，含两端 | 大于 50 亿元 |
| 当年预期尚无规模收入，非硬科技 | 股权估值，人民币 | 小于 3 亿元 | 3—10 亿元，含两端 | 大于 10 亿元 |

口径要求：

- PE = 本轮采用的股权估值 ÷ 同主体、同年度、同口径预测净利润；PS = 本轮采用的股权估值 ÷ 同口径预测营业收入。保留输入、来源、期间、币种、单位、公式和调整原因。
- 本轮明确投前估值时以投前为评分基准；只有明确投后估值时，可按投后计算并在理由中注明。仅当本轮全部为公司新增股权融资且金额明确时，才可用投后减新增融资推算投前；老股转让与复杂条款不直接相减。
- 无法确认投前／投后时，在融资章节注明；如果因此无法确定评分口径，估值评价写“无法判断”，不自行假设。
- 外币金额需要明确来源和日期的汇率换算为人民币后才能使用人民币绝对阈值；缺少可核验汇率时保留缺口。
- 恰好净利润 5,000 万元不进入规模盈利档；恰好收入 1 亿元不进入规模收入档。PE 30／100 倍、PS 3／10 倍及绝对估值阈值都归两星。

## 与投资策略契合度
- 内容：

| 评估理由  | 初步判断 |
| ----- | ---- |
| 一句话理由 | ⭐⭐⭐  |

- 分析指南：
  - 最高三颗⭐，最低一颗⭐
  - 投资策略注重安全性，追求胜率而非赔率。同时会考虑产业协同，如该公司的主营业务与“体育场馆运营、线下演艺、赛事活动、旅游”具备较强的业务协作或上下游关联，可增加一颗⭐。

## 风险评价
- 内容：用一小段话综合评价项目风险。首句点名项目风险高低；然后简述主要风险来源。
- 分析指南：对风险的定义是在基金存续期（七年）内本金发生永久性损失的可能性。可以从公司业务本身是否健康发展，从买入估值是否过高从而无下家接手，从对IPO的预期过于乐观等多角度来分析对本金损失风险的影响。
  
# 下一步建议
## 项目归类
- 内容：

| 类型             | 解释         |
| -------------- | ---------- |
| 重点推进/研究推进/保持跟踪 | 说明这个类型代表什么 |

- 分析指南
   - 重点推进：代表最符合当下投资偏好，应尽快推进下一步工作
   - 研究推进：代表与投资策略没有明显冲突，但尚有不确定之处，要主动进行更多的调研
   - 保持跟踪：代表与暂不符合投资策略，暂不主动进行调研工作
## 后续工作
- 内容：用表格形式列出

| 事项  | 完成标准 |
| --- | ---- |
|     |      |
- 分析指南：
  - 仅“重点推进”和“研究推进”需填写，“保持跟踪”的项目不需填写
  - 事项根据事实性信息的重要缺口和多维评价的无法判断事项来填写。
  - 对“重点推进”项目，“事项”列应补齐事实性信息的重要缺口和多维评价的无法判断事项，并且完成标准应更严格，一般应再次与项目方交流，并应进行线下的行业调研。
  - 对“研究推进”项目，“事项”列可仅列少数几个重要信息缺口，一般通过让项目方给增量资料以及进行线上二手资料研究为主。
  - 为了防止所列事项过于琐碎冗长，对“重点推进”项目，事项数不得超过8条；对“研究推进”项目，事项数不得超过5条。
