# 初筛报告 DOCX 导出

## 触发和登记

| 本次用户动作 | 处理 |
|---|---|
| 确认某版 Markdown 复核通过 | 登记明确的复核依据、复核人、日期及版本，将该 Markdown 状态登记为“已复核”，同一次任务直接生成该版 DOCX。复核过的其他版本留存原件。 |
| 明确要求 Word 版 | 从指定 Markdown 生成 DOCX，沿用其版本与复核状态。未经复核时文件名及报告信息用“待复核”。 |
| 仅要求生成、修改或提交初筛稿供复核 | 交付 Markdown。等该版收到明确复核确认后再自动导出。 |

复核指用户认定这一版通过。“收到”、局部修改意见、仅认可某一段、AI 自检通过等不足以更新复核状态。指向明确的“报告复核通过”可直接执行，无需询问是否导出。新版本独立复核。普通编制、旧版本巡查和移交不触发补导。用户本次另有安排时按本次指令执行。

初筛报告 DOCX 是本地衍生件。复核、阶段推进、冻结、发送和过程稿删除分别办理。若过程稿清理等待授权，照常完成 DOCX。自动导出是用户确认后的任务内动作，无需后台监控。若生成失败，保留已登记的复核状态，排查原因后补导同一版本。

## 文件和版式

- 文件名为 `项目名_初筛报告_vX.Y_已复核.docx` 或 `项目名_初筛报告_vX.Y_待复核.docx`。已有明确冻结授权的冻结版沿用“已冻结”。证据截止日、公司事实、数字单位、评分、归类理由和后续工作按源稿。
- 放在源报告目录下 `90_按需导出/YYYYMMDD-HHMM/`。用户明确指定目录时按其要求。已有相同源稿哈希、相同状态及本规范的合格 DOCX 时复用该文件；源稿变更后生成新批次，保留旧件和登记。
- 标题 24 磅微软雅黑加粗、居中。一级、二级、三级小节分别为 16、13、11 磅微软雅黑加粗，使用 Word 原生多级编号 `一、`、`（一）、`、`1、`，下级遇新的上级重新编号。
- A4 纵版，左右边距各 2.25 厘米。正文为 11 磅宋体，1.35 倍行距，首行缩进两个汉字。标题与下一段相连，页脚采用自动页码，标题、正文、表格、页眉、页码及星级均为纯黑色。保留源稿披露的密级。
- 表格为可编辑原生表格，浅灰加粗表头、白底和细灰横线，表格正文 10.5 磅宋体。跨页重复表头，整行同页，数值和比例列右对齐，星级居中，用黑色 `★` 显示对应星数。按内容分配列宽，说明文字列优先留足空间。财务空白原样保留。
- “项目归类”保留原归类及理由。其下追加三条适用情形，用 9 磅楷体，区别于正文。重点推进适用于最符合当前投资偏好、应尽快推进的项目。研究推进适用于与当前投资策略基本相容、仍需主动补充调研的项目。保持跟踪适用于暂不符合当前投资策略、以观察为主的项目。
- DOCX 省略“底稿与来源索引”“资料来源附注（脚注表）”“修订记录”及正文脚注。Markdown 主稿完整保留相关内容。

## 执行和验收

使用包内 [export_docx.py](../scripts/export_docx.py)。当前 Windows 环境使用 Python、PyYAML、lxml 和 Pandoc。脚本只读指定源稿并在本地生成 Word 文件，输出源稿和衍生件的 SHA-256。它不修改审核记录。用户的复核确认及版本登记由当前任务负责，脚本只校验传入的触发方式与源稿状态。

```powershell
python "<Skill目录>/scripts/export_docx.py" "<初筛报告.md>" --trigger review
python "<Skill目录>/scripts/export_docx.py" "<初筛报告.md>" --trigger requested
```

`review` 用于复核已登记的版本，源稿必须为“已复核”或“已冻结”。`requested` 用于用户明确要求的导出。优先读源报告 YAML 的 `project_name`、`version`、`status`；其他工作区历史报告无相应字段时，可根据已有版本记录用 `--project`、`--version`、`--status` 补齐。参数与 YAML 冲突时先核对版本。非标准输出位置使用 `--output-dir`。

用本地 Word、LibreOffice 或可用 DOCX 渲染器检查成品页。核对首页标题居中、标题序号、两字缩进、楷体说明、表格换页与页码。对照项目归类、评分和关键表格数字，确认略去指定附录，Markdown 未变。暂时无法渲染时，完成可做的结构和内容检查，交付时说明未完成版式预览。临时 PDF 或图片用于核对，验收后清理。

本工作台在 `04_决策与版本.md` 对应版本下记录触发依据、版本、状态、证据截止日期、DOCX 位置、导出时间及两份文件的哈希。其他工作区沿用当地记录方式。单独导出完成后交付 Word 文件链接，成稿和复核任务交付当次生成的主稿和 Word 版。
